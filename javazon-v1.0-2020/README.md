# Javazon 1.0

> **"This was my first programming project ever. I was 14, stupid, and—most importantly—completely clueless."**

## 👶 The Backstory

Javazon 1.0 was my freshman-year final CS project, built in late 2020 with two of my friends. None of us knew how to use objects (seriously), and we had just wrapped our heads around `for` loops.

We wrote **3385 lines** of pure, hardcoded switch-statement madness. And yes, it’s probably still the longest file I've ever worked on. If you wanted to change anything in the UI, good luck. You were in for some pain.

## 🧠 What I Learned

Despite the chaos, this project taught me a lot:
- Arrays and how to loop through them
- Basic I/O operations
- Setting timers
- Managing state without any formal structure (bless those global variables)
- Creative problem-solving under total ignorance

## 💡 Promocode System

I’m still weirdly proud of the promocode system I hacked together. I basically reinvented hash tables without knowing what a hash table was.

My thought process:
> “What if the *index* of each letter in the promocode is its value? Like, A is index 0. So A - 65 = 0. OMG I’M A GENIUS.”

## 🛠️ If I Did It Again...

Today, I could probably recreate this whole thing in under **400 lines** using actual objects and reusable components. And maybe even use a UI framework... you know, like a normal person.

## 📼 Pre-AI Era

This was **PRE-AI**. No Copilot. No ChatGPT. Just me and my friends. No one was there to tell us what we were doing wrong—we just had to *figure it out*.
